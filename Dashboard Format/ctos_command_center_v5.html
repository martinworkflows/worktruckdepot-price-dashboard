Utility Buyer Spec Guide
Working height — bucket trucks
Distribution: 40–55ft. Transmission ROW: 60–75ft. ORA/BOC = overcenter articulating — maximizes access over obstacles.
Insulation class
Class A ≤7.5kV · B ≤15kV · C ≤25kV · D ≤46kV · E ≤69kV. EIH = Electrically Insulated Hydraulics. Match to your voltage tier.
Digger derrick — sheave height
C4047 = 47.4ft, 24,750 lb for distribution pole-setting. C6060 = 60ft for transmission. Insulation rating critical for live-line work.
Pulling & tensioning — line type
BWT = conductor stringing. ODP = underground cable. CLP = continuous line puller for reconductoring. Match to your stringing method.
4x4 vs. 4x2 drivetrain
Storm response and ROW access require 4x4 for most utility fleets. 4x2 adequate for urban paved routes. New unit premium: ~$8–15K.
GVW & bridge law
F550/5500 = Class 5 (~18K GVWR). M2106 = Class 6–7 (26–33K). 6x6 for max off-road load. Verify bridge ratings on ROW routes.
